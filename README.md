# NotebookCSS

Enhance your NotebookLM experience with a professional folder system and a premium UI.

## Features
- 📂 **Custom Folders:** Organize your sources into meaningful groups.
- ⚡ **Bulk Actions:** Move or ungroup multiple sources in seconds.
- 🎨 **Premium UI:** Custom styling using Open Sans and a clean, native-feeling design.
- 🔍 **Error Handling:** Visual indicators for sources that fail to load.
- 🌓 **Dark Mode Support:** Seamlessly transitions with your system theme.

## Installation
1. Download this repository as a ZIP and extract it.
2. Open Chrome and go to `chrome://extensions/`.
3. Enable **Developer mode** (top right).
4. Click **Load unpacked** and select the extracted folder.

## How to use
- Click the **➕ Add Folder** button at the top of the Sources sidebar to create a folder.
- Drag and drop sources into folders, or select multiple sources and use the **Move to** menu.
- Use the **Ungroup** button to move sources back to the "Ungrouped" section.
- Collapse/expand folders by clicking on their headers.
